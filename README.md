# Tailwind Template

Template inicial para projetos com Vite, Tailwind CSS v4 e JavaScript.

## Tecnologias

- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [@tailwindcss/vite](https://tailwindcss.com/docs/installation/using-vite)

## Requisitos

- Node.js 18 ou superior
- npm

## Instalação

Clone o repositório e instale as dependências:

```bash
git clone <url-do-repositorio>
cd tailwind-template/tailwind-template
npm install
```

## Desenvolvimento

Inicie o servidor local:

```bash
npm run dev
```

Depois, acesse a URL exibida pelo Vite no terminal.

## Build de produção

Gere os arquivos otimizados:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```

## Estrutura

```text
tailwind-template/
├── index.html
├── package.json
├── vite.config.js
├── public/
└── src/
    └── style.css
```
